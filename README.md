<h1 >🏏 RCB Zone</h1>

<p >
  A modern and responsive fan website dedicated to <b>Royal Challengers Bengaluru (RCB)</b>, 
  built using <b>HTML</b>, <b>CSS</b>, and <b>JavaScript</b>.
</p>

<p >
    🌐 Live Demo
  <a href="http://rcbzone.vercel.app/" target="_blank">
    http://rcbzone.vercel.app/
  </a>
</p>

<h2>✨ Features</h2>

<ul>
  <li>🏏 Dedicated RCB fan website</li>
  <li>📱 Fully responsive design</li>
  <li>🎨 Modern and attractive UI</li>
  <li>⚡ Smooth animations and transitions</li>
  <li>🖼️ Interactive image sections</li>
  <li>🔥 Stylish cricket-themed layout</li>
  <li>🌙 Dark themed sports interface</li>
  <li>🚀 Fast and optimized performance</li>
